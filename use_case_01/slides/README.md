# Slides — Use case 1

`slides.pdf` is the deck as it was projected: one picture per slide, with the argument
spoken rather than written on it. So it reads as a set of diagrams, and the words that
went with them are not in this file.

What was said is in the material. Each concept page in [`../concepts/`](../concepts/)
carries the idea its slide showed, worked all the way through on the real Kabini material,
and the section in [`../demo/`](../demo/) carries every claim with its source. A
participant reading afterwards should read those; the deck is here to jog the memory of
somebody who was in the room.

The editable deck, the speaker notes and the image prompts stay in the training's research
repository. This folder is regenerated on each delivery and holds the PDF alone.
